# Bookiyah Women's Safe Driving Platform

Bookiyah is a women-focused driving and ride-booking application designed with safety and convenience in mind. The platform aims to provide women with a safer transportation experience by connecting them with verified female drivers.

## About the Project

Bookiyah was developed to address safety concerns faced by women while using transportation services. The application provides a platform where women can book rides, manage their trips, and access transportation services with a stronger focus on security and trust.

## Key Features

- Women-focused ride booking
- Verified female drivers
- User authentication
- Ride booking and management
- Driver and passenger management
- Safety-focused transportation experience

## Technologies Used

- Python
- Application Development
- User Authentication

## Project Purpose

The main purpose of Bookiyah is to create a safer and more comfortable transportation solution for women while making the ride-booking process simple and convenient.
